The 6-Agent Swarm

Each agent has a highly specialized role and works concurrently.

1. GitHub Scout Agent

Monitors repository activity, commit histories, and programming language statistics via the GitHub API, automatically drafting technical blog updates.

2. Dashboard Agent

Calculates telemetry metrics and uses LLMs to dynamically estimate live salary ranges based on current market trends and recently acquired skills.

3. Portfolio Sync Agent

Automatically keeps Python knowledge base files, project listings, and resumes perfectly synchronized across the entire stack.

4. MCP Engineer Agent

Exposes the ecosystem's internal telemetry as standard FastMCP tools so external AI assistants (like Claude) can read live portfolio stats.

5. Docs Agent

Maintains the internal skill files, chatbot context instructions, and interactive API documentation to keep the RAG agents aware of new changes.

6. Readme Agent

Auto-generates stunning developer documentation and architecture diagrams directly into the project's root README.md.
