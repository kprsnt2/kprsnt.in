# agent_vault

Private essence of Prashanth's agentic activity, generated by
`~/.agent-memory/scripts/build_vault.py`. **No raw logs are stored here** — only
curated summaries, per-project essence, analytics and a search index.

The deployed artifact is `vault.enc`, an **encrypted** bundle (Fernet, key derived
from `AGENT_VAULT_TOKEN` via PBKDF2). Plaintext JSON/markdown stay local and are
gitignored, so the public repo never contains the essence.

Served (unlisted) at `/vault/<token>` — no nav button.
